# Selected biome artwork

## Two art directions

- `terrain/`: elevated downward views with no sky or horizon, showing continuous
  terrain suitable for repeated use across the board. These are not guaranteed
  seamless textures. The earlier aerial sunset mountain candidate belongs here.
- `scenic/`: individual landscape compositions with focal points, depth, and
  freedom to include sky or a horizon. The selected hex-friendly mountain scene
  starts this set. Other scenic biomes remain to be explored one at a time.

Both sets should retain each biome's palette. Scenic compositions should keep
important features inside a point-up hexagonal crop. Existing root-level files
are preserved; the terrain set is now applied to the browser board. Scenic artwork remains separate for later use.

The terrain images share a general viewpoint, though the shallow-seas image is
closer to overhead than the other illustrations. A final consistency pass can
refine that difference after comparison on the board.
